- FEEDBACK MOMENT (on Submit: record, render feedback in place keeping prompt+visual, move focus to feedback region, announce aria-live polite). NEVER a bare icon.
  STATE A CORRECT: CheckIcon in 22px success-bg circle (status-mastered) + body 15/600 status-mastered "Correct". ## §4 Full-loop demo (both paths)
ACCELERATING: Home RECOMMENDED NEXT → Learn (slope P1 sport plane, drag→rate) → Practice streak builds (dots green), correct marks line green, reaches P3 neutral item correct → Summary "Developing→Near mastery" or "→Mastered", PHASE REACHED Neutral transfer, verdict Advance, "Continue to {next}". Competence via status movement + transfer, no score.
STRUGGLING: Learn prereq-lock → routed to weak prereq. Practice miss+tag → momentum resets quietly, marked-up "you" dashed vs "correct" solid, TUTOR diagnoses+reframes in sport+bridges neutral, "Try again" → Summary status held or "→Review", WHAT TO FIRM UP plain-language tag, verdict Review/Remediate, "Review {prereq}". Errors framed as information throughout.
